# Тапалка 🪙

Простая игра-кликер на Python + Tkinter. Жми на кнопку, копи монеты, покупай улучшения и пассивный доход.

## Возможности
- Тап по кнопке приносит монеты
- 4 улучшения: сильнее тап или автодоход в секунду (цена растёт с каждым уровнем)
- Автосохранение прогресса в JSON (каждые 10 секунд и при закрытии)
- Сброс прогресса одной кнопкой
- Игровая логика отделена от интерфейса и покрыта тестами

## Запуск
Нужен Python 3.10+ (Tkinter входит в стандартную поставку).

```bash
python main.py
```

> На Linux, если нет Tkinter: `sudo apt install python3-tk`

## Тесты
```bash
pip install -r requirements.txt
pytest
```

## Структура
```
tapper_game/
├── main.py            # точка входа
├── tapper/
│   ├── logic.py       # GameState, улучшения, формулы цен
│   ├── storage.py     # сохранение/загрузка JSON
│   └── ui.py          # окно на Tkinter
└── tests/
    └── test_logic.py  # unit-тесты (pytest)
```

## Как устроена экономика
Цена улучшения = `base_cost * growth ^ уровень`, округляется вверх.
Новые улучшения добавляются одной строкой в список `UPGRADES` в `tapper/logic.py`.

## Идеи для развития
- Достижения («100 тапов», «1000 монет»)
- Оффлайн-доход: начислять монеты за время, пока игра была закрыта
- Звук и анимации при тапе
- Редкие бонусы, которые случайно появляются на экране
- Перенос на pygame или веб (Flask + JavaScript)
